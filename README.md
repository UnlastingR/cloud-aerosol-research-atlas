# Cloud Atlas

**全球云与气溶胶研究图谱**

[探索研究地图](https://tracks.fyzure.fyi)

Cloud Atlas 聚焦船迹云、气溶胶—云相互作用及卫星云遥感，梳理全球相关研究团队及其代表成果。交互式地球呈现研究机构的地理分布，并以学者、论文和合作关系串联领域内的重要研究方向。

## 探索内容

- **全球研究地图**：浏览团队分布，探索区域内的研究力量与学术联系。
- **团队档案**：了解研究重点、代表学者及主要学术成果。
- **文献脉络**：追踪船迹识别、云的动态演变、物理机制与辐射效应研究。

## 资料来源

图谱依据公开学术论文、研究机构资料及相关学术数据库整理。团队位置采用机构所在地的地理坐标，文献条目提供原始出处，内容随领域发展持续更新。

*资料更新：2026 年 10 月*
